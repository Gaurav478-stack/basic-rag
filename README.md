 # basic-rag
A Python-based semantic search/retrieval system using Sentence Transformers for embeddings and FAISS for vector similarity search.

This will be a repo of making and completing this project in versions . with each version there will be an incrementation of the features, and complexity of the RAG model eventually making it a complete RAG used in today applications and LLMs 
.This is a learning journey of understanding of the thing which is used in retrieval and generation of output in todays LLMs.
